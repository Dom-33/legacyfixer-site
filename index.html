Get started in minutes

Start with a safe onboarding path

LegacyFixer is a self-service GitHub App. Begin with passive dependency-security scans and enable pull requests only when you're ready.

  1. 1
    Sign in with GitHub Create your workspace and connect selected Python repositories.
  2. 2
    Run passive scans first Record vulnerability findings without opening a pull request.
  3. 3
    Enable PRs deliberately Control optional fix pull requests through repository settings.
7 days · up to 3 connected repositories

The trial ends after seven days, even if fewer than three repositories are connected. Access can be revoked in GitHub settings at any time.
