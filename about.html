About LegacyFixer

Independent Python dependency-security maintenance, with conservative defaults and human review.

The product

LegacyFixer is a GitHub App for maintainers of Python repositories. It runs dependency-security scans, records results, and can propose fixes through reviewable pull requests when explicitly enabled. Passive scanning comes first; LegacyFixer never auto-merges changes.

Founder

LegacyFixer was founded by Domnita Tudor, who leads its product direction, testing, and release decisions. The project has been built through sustained human–AI collaboration, iterative implementation, and hands-on technical validation.

Verify the founder's work and project portfolio: GitHub — Dom-33 · Devpost — Domnita Tudor.

Our approach

LegacyFixer prioritizes explicit repository permissions, understandable scan results, and optional pull requests for human review. Its current scope is Python dependency maintenance, not a general-purpose source-code security audit.
