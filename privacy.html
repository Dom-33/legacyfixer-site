Privacy policy

This page describes the limited information LegacyFixer processes during GitHub sign-in, repository connection, and dependency-security scans.

Information processed

LegacyFixer may process repository metadata, GitHub installation identifiers, selected repository names, branch information, dependency files needed for scanning, scan results, job status, timestamps, failure reasons, and pull request metadata if a pull request is created.

Purpose

This information is used to run dependency-security scans, record scan status, diagnose operational failures, and provide maintainers with reviewable results.

Trial access

During trial, LegacyFixer should be used only with repositories you are comfortable evaluating in a dependency-maintenance workflow.

Do not submit secrets, access tokens, private logs, confidential source code, or sensitive repository contents through email or public issue comments.

Optional website analytics

With your choice, we use Google Analytics 4 to measure website usage and onboarding events such as clicks on Start free trial, successful GitHub sign-in, and confirmed repository connections. Google Analytics is not loaded until you accept optional analytics. You may reject or change your choice using the Analytics preferences control.

We do not deliberately send GitHub usernames, email addresses, workspace IDs, repository names or IDs, or URL query parameters in analytics events. Analytics preferences are stored in a first-party cookie, shared between legacyfixer.ai and app.legacyfixer.ai when supported by your browser. Google may process analytics data under its own terms and privacy policy.

Launch video hosted by YouTube

The landing page offers an optional YouTube launch video. We do not load the YouTube player until you select Play. Once you do, YouTube/Google may receive technical information from your browser and process data according to Google's privacy policy. You may alternatively open the video on YouTube directly. This video choice is separate from optional Google Analytics consent.

Contact

For privacy questions or removal requests, email contact@legacyfixer.ai.
